# InkCard (`webapp/`)

AESL0213C-TLSR8250 2.13" 黑白红三色墨水屏卡片助手与硬件调试工具集（React 19 + Vite 8 + Tailwind CSS v4 + React Router Data Mode）。

## 常用命令

```bash
pnpm install      # 安装依赖
pnpm dev          # 本地开发（默认 http://localhost:5173）
pnpm test         # 运行 Vitest 协议与核心单元测试
pnpm lint         # 运行 oxlint 代码检查
pnpm build        # TypeScript 类型检查 + 生产构建（输出到 dist/）
pnpm preview      # 本地预览生产构建产物
```
