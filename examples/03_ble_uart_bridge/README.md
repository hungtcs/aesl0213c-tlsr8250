# 03_ble_uart_bridge — 正式版 BLE 5.0 串口透传固件

基于 `TLSR8250`（`ZK_TESR21S_V2.1`）的正式可用 BLE ↔ 硬件 UART 双向透传固件（预编译固件见 `firmware/ble_uart_bridge.bin`）。

## 核心特性

- **高速稳定透传**：支持 ATT MTU 协商至 **247 字节**（单包最高 **244 字节**）+ **DLE**，搭配 **1KB UART 环形缓冲区**、满包/15ms 超时自动组帧及 BLE TX FIFO 背压重试队列。
- **双通用 GATT 服务 + BLE OTA**：
  - **Nordic UART Service (NUS)**：`6E400001-B5A3-F393-E0A9-E50E24DCCA9E`
    - RX（手机 → 板子，Write / WriteWithoutRsp）：`6E400002-B5A3-F393-E0A9-E50E24DCCA9E`
    - TX（板子 → 手机，Notify / Read）：`6E400003-B5A3-F393-E0A9-E50E24DCCA9E`
  - **通用 16-bit 透传服务（兼容 HM-10 / 微信小程序等）**：`0xFFE0` / 读写通知特征 `0xFFE1`
  - **Telink 标准 BLE OTA**：`00010203-0405-0607-0809-0A0B0C0D1912` / `...2B12`（可直接配合 `web/ble_ota.html` 无线升级，OTA 写入区 `0x40000..0x73FFF`，安全保护 `0x76000` 原厂 MAC 与 `0x7A000` 配置区）
- **原厂唯一 MAC**：自动读取 Flash `0x76000`，默认广播名 `ZK_UART_<MAC后4位>`。
- **完整 AT 指令 + Flash 掉电保存**：配置保存在 Flash `0x7A000`（带魔数与 CRC16 校验）。
- **片上 14-bit SAR ADC**：支持 `AT+VBAT?` 实时监测芯片供电电压（mV）。
- **硬件看门狗（2000ms）+ 双 LED 状态指示**：
  - 广播中：绿灯每 2 秒闪 1 次
  - 已连接：绿灯常亮；BLE→UART 闪绿灯，UART→BLE 闪红灯
  - OTA 升级中：红绿灯交替快闪

## 编译与烧录

```bash
# 编译
make -C examples/03_ble_uart_bridge all

# SWS 一键烧录
make -C examples/03_ble_uart_bridge flash-sws
```

硬件引脚分配：

- **UART**：`TX = PC2`、`RX = PC3`（默认 `115200 8N1`）
- **LED 指示灯**：红灯 `PB4`、绿灯 `PB5`（保持原有状态指示不变）
- **硬件控制引脚（复用拆屏后的空闲 EPD 引脚）**：
  - **`STATE` 输出 = `PA1`**（原 `EPD_RST`）：`HIGH (3.3V)` = BLE 已连接，`LOW (0V)` = 未连接
  - **`AT_KEY` 输入 = `PA0`**（原 `EPD_BUSY`，内置 10K 上拉）：悬空 = 正常透传，**接地拉低 = 强制切入 AT 模式**

> **⚠️ 未拆屏风险提示**：若板子仍连接着墨水屏（且屏幕未通电），断电墨水屏芯片内部的 ESD 保护二极管可能将 `PA0`（`AT_KEY`）下拉为低电平，导致连上蓝牙后始终处于 AT 模式无法透传，同时 `PA1` 输出高电平时也会向断电屏幕产生微弱寄生漏电。**使用本固件的 `STATE`/`AT_KEY` 功能时，请先断开/拆除坏屏排线**（剪断排线前务必断电，并确保切口处各铜箔无毛刺短接）；若在完好墨水屏板子上使用，建议在 `src/app.c` 中禁用 `PIN_AT_KEY` 检测。

## 配套网页上位机

运行 `pnpm --dir webapp dev` 后，在 Chrome / Edge 打开：
`http://localhost:5173/#/tools/uart`

可在同一页面同时连接 **Web Bluetooth（蓝牙侧）** 与 **Web Serial（CH340 串口侧）**，支持双向透传对照、ASCII/HEX 切换、100B 长包测试及一键可视化配置所有 AT 参数。

## AT 指令表

- **未连接时**：串口默认处于 **AT 模式**（指令以 `\r\n` 结尾）。
- **已连接时**：串口默认处于 **纯透传模式**；连续发送 `+++`（前后静默 ≥15ms）可切入 AT 模式，发 `AT+EXIT` 返回透传。

| 指令                   | 说明                                                                                   |
| :--------------------- | :------------------------------------------------------------------------------------- |
| `AT`                   | 测试通信，返回 `OK`                                                                    |
| `AT+HELP`              | 打印指令帮助                                                                           |
| `AT+INFO?`             | 查询版本、MAC、名称、波特率、功率、广播间隔、状态、当前 MTU、VBAT 电压                 |
| `AT+VBAT?`             | 查询当前供电电压（mV）                                                                 |
| `AT+NAME=<str>`        | 修改蓝牙名称（1~20 字符），掉电保存并立即生效                                          |
| `AT+BAUD=<rate>`       | 修改串口波特率（`9600`/`19200`/`38400`/`57600`/`115200`/`230400`），掉电保存并立即切换 |
| `AT+TXPWR=<0..4>`      | 修改射频功率（`0:-9.9` / `1:-3.6` / `2:0` / `3:+3.0` / `4:+10.3 dBm`），掉电保存       |
| `AT+ADVINT=<20..2000>` | 修改广播间隔（ms），掉电保存                                                           |
| `AT+ECHO=<0\|1>`       | 开关 BLE 接收回显（默认 `0` 纯透传），掉电保存                                         |
| `AT+LOG=<0\|1>`        | 开关串口状态提示（`+CONNECTED`/`+DISCONNECTED` 等），掉电保存                          |
| `AT+DISC`              | 主动断开当前 BLE 连接                                                                  |
| `AT+EXIT`              | 连接状态下退出 AT 模式，恢复纯透传                                                     |
| `AT+RESET`             | 软件重启                                                                               |
| `AT+DEFAULT`           | 恢复出厂默认配置并重启                                                                 |
